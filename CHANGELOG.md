# Changelog

All notable changes are documented here. The project follows Semantic Versioning while its public interfaces mature.

## 0.2.0 - 2026-07-20

### Added

- Versioned public API for collection, evaluation, graphing, diffing, reporting, and rule verification.
- Effective permission constraints for explicit denies, permissions boundaries, SCPs, session scopes, conditions, and resource exclusions.
- Stable path fingerprints and new, open, improved, worsened, resolved, reopened, and unverified lifecycle states.
- `diff` and `rules` CLI command groups.
- Change-first offline report with practitioner filters and evidence drill-down.
- Apache-2.0 licensing, project governance, threat model, benchmark fixtures, and CI/release automation.

### Changed

- Minimum Python version is now 3.10.
- Inventory schema version is now 2.0.

## 0.1.0

- Initial packaged local scanner, rules, graph export, and static report.
